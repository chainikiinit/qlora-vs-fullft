# Гипотезы и их статус

Заполняется по ходу работы. Опровергнутая гипотеза с объяснением ценится не меньше подтверждённой.

| № | Гипотеза | Как проверяем | Статус | Результат и объяснение |
|---|----------|---------------|--------|------------------------|
| H1 | При ~7k примеров QLoRA отстаёт от полного FT по точности на GSM8K не более чем на 1–2 п.п. | core, 3 seed, парное сравнение на одних задачах | не проверена | |
| H2 | QLoRA снижает пиковую память в разы, но замедляет шаг обучения | peak_mem_allocated_gb, tokens_per_s | не проверена | |
| H3 | Разрыв QLoRA и полного FT растёт с размером выборки | size + meta | не проверена | |
| H4 | Ранг LoRA влияет сильнее, чем квантизация (LoRA-16bit vs QLoRA при одном r) | rank | не проверена | |
| H5 | Полный FT сильнее роняет ARC/MMLU/HellaSwag, чем LoRA/QLoRA | eval.yaml, сравнение с baseline | не проверена | |
